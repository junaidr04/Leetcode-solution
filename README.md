Overview

This repository contains my solutions to various LeetCode problems categorized by topics.
The purpose of this repository is to practice and prepare for software engineering interviews, especially for Google and other tech companies.


🗂️ Topics Covered list

Arrays – Common array problems including prefix sums, rotations, and subarrays.

Hashmaps – Frequency counting, two-sum problems, and other hash table applications.

Linked List – Singly and doubly linked list problems including reverse, cycle detection, and merge.

Queue – Queue, deque, and priority queue problems.

Searching and Sorting – Binary search, quicksort, mergesort, etc.

Sliding Window – Maximum/minimum window, substring problems.

Stack – Monotonic stack, balanced parentheses, expression evaluation.

Strings – Palindrome, substring, anagram, and string manipulation problems.

Tree – Binary Tree, Binary Search Tree, tree traversal, and tree problems.

Two Pointers – Two-pointer approach for array and string problems.

Graphs – Graph representation, BFS, DFS, shortest paths, cycles, and connected components, Dijkstra, Bellman-Ford, Floyd-Warshall, Topological Sort, MST (Kruskal, Prim).

Heap – Min heap, max heap, priority queue problems, and heap-based algorithms.

Dynamic Programming (DP) – Classic DP problems, memoization, tabulation, knapsack, LIS, etc, DP on trees, bitmask DP, DP on grids.

Greedy Algorithms – Interval problems, activity selection, Huffman coding, and optimization problems.

Tries – Trie construction, prefix search, and word problems.

Recursion – Recursive problem solving, recursion trees, and basic recursion patterns.

Backtracking – N-Queens, subsets, permutations, and constraint satisfaction problems.

Bit Manipulation – XOR, AND, OR tricks, subset generation with bits, single number problems.
